# F7R flag radio

Voice calls supplied by the F7R project owner. Edited into individual mono PCM clips with a voice bandpass, gentle gate, compression, level matching and short fades. The buzz and microphone clicks were synthesized specifically for this app.

Countdown numbers are separate recordings and follow the server deadline; a fixed ten-second recording is never used to decide when a flag changes. Urgent new flag calls interrupt older audio; stale queued numbers are dropped. Messages and repeated polls do not repeat announcements. The source recording is not distributed.
