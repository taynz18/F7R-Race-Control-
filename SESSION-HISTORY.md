# F7R session history
Live snapshots are recorded automatically by a database trigger from the date this feature was enabled. No new receiver is required.
Open Previous sessions and sign in using the same F7R driver account. Saved sessions are shared with signed-in accounts; guests cannot read the archive. Approved flag admins additionally see recordings awaiting a decision.
After racing, stop uploading or leave the game session, refresh this page, name the recording and choose Save session. This freezes that recording and publishes it to driver accounts. Discard hides and stops that recording; data is retained internally, not permanently deleted. Incomplete sessions can be saved. Each game UID is independent so later races cannot replace a recording.
Approximately one complete telemetry sample every two seconds is retained, with additional samples for lap/status transitions. A lap counts only when the receiver observes a lap-number increase with a valid last-lap time. Gaps are not reconstructed. Best/average/consistency and pit entries are observed statistics. Results are last known running order, not official final classification. JSON export contains all recorded fields.
Session type is only identifiable if supplied by the receiver; qualifying and races both record. Data already overwritten before this feature was enabled is unavailable. Private data remains private/missing as supplied by the live receiver.
Tables: f7r_recordings, f7r_recording_samples. Admin save/discard RPC: f7r_finish_recording. Trigger function is in non-exposed f7r_private, with direct execution revoked. Guests have no table privileges. Recording/sample tables enforce RLS, ordinary accounts can read saved rows only. No public writes to samples and no direct account writes to captured data.
